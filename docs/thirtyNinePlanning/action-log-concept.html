Action log redesign — concept

Concept reference for the implementer. Placeholder colors/icons — build with the game's existing log components, not this palette.

The cut: events vs. state

The log should narrate events. State — CT, HP/MP, status counts, KO timers — already lives in the turn queue, unit cards, and status badges, so the log re-narrating it is both noise and a duplicate. Top line shows events only; state collapses into a per-turn ledger.

Three levers

Consolidate — multi-line mechanical sequences become one event (Burn tick + its damage + its expiry → one line).

Relocate — the KO timer (KO 1 / 2 / 3 — fading) leaves the log entirely and shows on the unit.

Encode — an icon gutter plus weight and color replace the [tick] / [end] / [ko] text tags, restoring the significance hierarchy the flat log lost.

Default view

Events only. Click a turn header, or Show ledger, to reveal the full mechanical detail — kept for replay/debug completeness, not deleted.
